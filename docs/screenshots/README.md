# Application Screenshots Directory

This directory contains visual captures and reference previews of the Smart College Complaint Management System UI/UX flows.

## Referenced Screenshots
1. **`landing.png`**: Public Landing Page with complaint category cards, operational workflow steps, and real-time grievance statistics counters.
2. **`dashboard.png`**: Student & Administrator Role-Adaptive Dashboard featuring KPI metric cards, active filters, and complaint registries.
3. **`new-complaint.png`**: Student Grievance Lodging Form with category dropdown, interactive priority level selectors, exact location input, and live ticket preview.
4. **`timeline.png`**: Detailed Incident Lifecycle View featuring the 6-stage visual milestone progression (`Submitted` → `Under Review` → `Assigned` → `In Progress` → `Resolved` → `Closed`), student info, and admin status updating controls.
5. **`admin.png`**: Master Administrator Management Console with multi-criteria search/filtering, category distribution bars, and the quick triage & staff assignment modal.
